# Cybersecurity Learning Lab

A practical documentation repository tracking my development in cybersecurity, with a focus on Security Operations (SOC), network defense, security monitoring, and incident investigation.

## About This Repository

This repository documents hands-on cybersecurity exercises, technical investigations, observations, and lessons learned as I build foundational skills for a career in Security Operations.

My approach emphasizes understanding security concepts through practical experimentation, structured analysis, and consistent documentation.

- Wireshark
- DNS and TCP/IP Fundamentals

- Linux Fundamentals
- SIEM Fundamentals

- Findings and lessons learned
